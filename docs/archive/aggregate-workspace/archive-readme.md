# Archive

本目录用于放置历史评审、旧路线图和旧协议资料。

归档文档只能作为问题背景或历史证据，不能作为当前 IPC v2 设计规范。当前设计入口是：

- `../../protocol.md`
- `../../development.md`
- `../../design/web-host-overlay.md`

历史文档如果提到 MemoryStacks、旧 Capture v2、单槽 flag、旧 `.NET HeadlessBrowser` 或兼容迁移路线，不代表当前目标架构仍保留这些设计。

`reviews/` 下的评审报告也是历史证据，主要用于追溯性能问题、协议迁移过程和当时的工程风险。整理、实现或排障时应先看当前 Lichora 文档，再把历史报告中的结论按当前代码重新验证。
